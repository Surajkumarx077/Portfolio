# Frontend Developer Portfolio

A modern, high-aesthetic portfolio built entirely with HTML, CSS, and JS (No frameworks).

## Features
- Clean, premium design aesthetics
- Glassmorphism UI elements
- Sleek dark/light theme toggle
- Smooth micro-animations
- Completely responsive layout
- Component-based architecture using vanilla JS to inject HTML

## Getting Started
To view this portfolio, you simply need to open `index.html` in your web browser. 
Since it uses Javascript `fetch` to load components (like the Navbar and Footer), you might need to run it through a local server if you're loading it via `file://` protocol and your browser restricts cross-origin requests.

Recommended approach:
1. Use VS Code extension "Live Server"
2. Or use Python: `python -m http.server 8000`
